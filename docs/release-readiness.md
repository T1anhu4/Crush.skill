# v3 发布检查 · 2026-09-07

当前定位：源码开发预览，不是稳定版升级，也未通过长期自然度验收。不要将自动化测试通过写成“所有 bug 已清零”。

## 本轮可验证交付

- CLI 安装：源码入口，隔离候选环境验证旧版与 v3 后替换；升级备份，失败保留旧程序，数据不删除；支持无网络安装测试。
- Skill 安装包：包含共享 `crush_core` 与 `v3.py`；过滤数据库、缓存、隐藏文件与链接。v3 必须显式选择，旧会话不悄悄切换引擎。
- 导入隐私：safe 去掉发送者标识、媒体路径，扩充规则脱敏；非法模式及含糊 full 参数拒绝。不能保证消除一切可识别信息，存量导入须删除后重导。
- 迁移：只读源库、先预览、显式确认、原始资料归档、默认暂停、幂等、失败事务回滚；年龄未知或未成年的旧身份仅可归档。旧关系数值与推断不自动成为新内核事实。
- 时间与记忆：来源约束、同主题修正、跨天沉淀、重启一致性、撤回与分支隔离。CLI 调度仅处理明确指定的会话。
- 生活延续：预设八阶段后，自由对话可在实际交互时每日新增一条虚构生活事实；独立存储、重复文本拒绝，未分享事实保持私有。不是全天持续思考，也不是无限内容质量保证。
- 评测：全新临时库，虚构成年角色，第 1、3、14、30 天稀疏场景；生成逐轮证据和重复率诊断。真实模型必须单独授权，不使用私人队列作为测试。

## 仍不满足正式发布的项目

1. 当前模型已多轮合成联调；最新事实编辑版本的一轮 15/15 交付、自动化全部通过，偏好品种混淆、季节推断和反复追问误会未在本轮复现。仍有未明示用户行为及角色习惯的漏检，详见[真实联调记录](2026-09-07-live-evaluation.md)。所有角色的多轮独立人工体验评分尚未完成，不能发布为自然度达标。

   已补本地回归和局部修复：显式时间上下文、生成前饮品偏好记忆、旧来源防覆盖、撤回恢复、未调度生活示例隔离、事实编辑、上限一次重写及安全错误分类。首轮 FAIL 保留为历史记录，不被最新通过结果抹掉。
2. 已有 v3 Skill 的共享 API 适配器，不是所有宿主的原生模型接入。无需额外 API 的宿主生成、各平台后台调度还未实现及验证。
3. 本轮没有进行新的跨浏览器视觉验收；前端自动化与构建不代替真实窗口、移动端、输入法和减弱动态效果验收。
4. 远程依赖下载、公开发行安装、长期负载、自然度评估仍需独立验证。原预览服务处于停止状态；恢复会处理私人待发送任务，不能作为无害检查自动启动。

## 复现

```sh
.venv/bin/python -m pytest tests -q
npm --prefix web test
npm --prefix web run build
bash scripts/smoke_test.sh
.venv/bin/python -m crush_core.evaluate --output /tmp/crush-release-evaluation.json
```

评测输出路径必须不存在。退出码 2 表示自动化通过但自然度门禁未通过，不可忽略后宣布发布成功。测试产物包含合成内容；私人库、密钥、真实聊天与本地导出不得提交仓库。
